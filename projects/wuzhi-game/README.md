# Wuzhi Game

《无职转生》题材的人生 RPG 项目。设计文档、数据与代码都放在这个目录下。

## 目录

| 目录 | 用途 |
|---|---|
| `docs/` | 设计文档：规划书、系统设计、世界观整理、决策记录 |
| `data/` | 数据表：人物、地点、事件、技能、物品（JSON / YAML / CSV） |
| `src/` | 代码：规则引擎、场景逻辑、工具脚本 |

## 状态

骨架已建立，等待正式规划书与任务。

## 约定

- 每个阶段完成即提交一次，提交信息说明「改了什么、为什么」。
- 资料类大文件（电子书、拆分文本、笔记）不入库，见根目录 `.gitignore`。
