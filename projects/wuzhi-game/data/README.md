# data

结构化数据目录。

建议组织：

| 文件 | 内容 |
|---|---|
| `characters.json` | 人物：身份、人格、目标、能力、关系、认知 |
| `locations.json` | 地点：层级、出入口、可达关系 |
| `events.json` | 事件：条件、阶段、参与者、时间窗 |
| `skills.json` | 技能：前置、消耗、效果、表现 |
| `items.json` | 物品：来源、用途、归属、价值 |
| `timeline.json` | 年表：甲龙历年号与锚点事件 |

约定：

- 所有条目带稳定 `id`，不随显示名变化。
- 每条内容标注来源（卷／章节），便于回查原文。
- 数值单位与换算写进 `data/README.md` 或对应 schema。
