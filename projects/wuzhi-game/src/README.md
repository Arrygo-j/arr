# src

代码目录。

计划中的分层（与规划书的职责边界一致）：

```
src/
├── core/        世界状态、行动服务、事务提交
├── time/        时间推进与调度
├── npc/         人格、日程、行为选择
├── event/       事件条件、阶段、分支
├── combat/      战术空间、行动队列、效果结算
├── growth/      学习、研究、能力登记
├── economy/     资源账本、交易、生产
├── save/        快照、校验、迁移
├── content/     内容导入与校验
└── tools/       制作期工具（数据检查、截图、导出）
```

原则：规则层不依赖 UI、动画或模型供应商；AI 只负责表达与有限提案，不直接改世界状态。
